# 郑圆玲的工作台 🌸

一个粉色主题的个人工作台 Web App，移动优先，可离线使用（数据保存在 localStorage）。

## ✨ 功能特色

### 📋 主页（工作台）
- 每日一句（10 句励志语录 + 换一句）
- 🐚 扇贝打卡卡片（累计天数 + 今日打卡按钮）
- ⏰ 倒计时卡片（距目标日 2026/12/19 还剩 X 天）
- 📋 今日概览（任务打卡，可勾选 / 新增 / 删除）
- 🐱 团团状态快速预览

### 🐱 团团的小院（底部第二 Tab）
- 橘猫「团团」emoji 头像
- 4 阶段进化系统：
  - 0-5 次喂食：😿 饥饿状态
  - 6-30 次喂食：🐱 成长中
  - 31-100 次喂食：😺 健康
  - 100+ 次喂食：😻 幸福
- 每次完成今日任务自动喂食，每日上限 5 次
- 状态条：饥饿度 / 心情 / 阶段进度

### 📖 侧边栏功能页
- **学习** 📖：今日学习时长统计 + 学习计时器 + 英语词汇（8 个单词）
- **瑜伽** 🧘‍♀️：今日完成 / 累计动作 / 训练天数统计，动作可勾选 + 增删（预设：下犬式、猫牛式、婴儿式、眼镜蛇式、桥式、鸽子式）
- **养生** 🪷：泡脚 / 喝温水 / 早睡 / 护肤 任务，可增删
- **存钱** 💰：收支记账（8 个支出分类 + 4 个收入分类），统计今日收入 / 支出 / 结余
- **经期** 🌷：周期记录 + 月视图日历 + 智能预测下次经期
- **扇贝打卡** 🐚：累计天数 + 最近 7 天打卡条
- **倒计时** ⏰：距目标日大数字 + 年度进度条

## 🚀 使用方法

### 本地直接打开
直接双击 `index.html` 即可在浏览器中打开使用。

> ⚠️ 部分浏览器对 `file://` 协议下的 localStorage 有限制，建议用本地服务器打开。

### 启动本地服务器
```bash
# Python 3
python3 -m http.server 8000

# Node.js
npx serve .

# 然后访问 http://localhost:8000
```

### 手机预览
启动本地服务器后，使用 Chrome / Safari 的"开发者工具"切换到移动端视图，或者直接用手机访问同一局域网的 IP。

## 💾 数据存储

所有数据保存在浏览器的 localStorage 中，键名前缀 `zhyl_`：

| 键名 | 用途 |
|------|------|
| `zhyl_today` | 当前日期标记（用于每日重置） |
| `zhyl_tasks_{YYYY-MM-DD}` | 每日任务勾选状态 |
| `zhyl_custom_tasks` | 自定义任务列表 |
| `zhyl_shellbean_*` | 扇贝打卡数据 |
| `zhyl_cat_data` | 团团喂食数据 |
| `zhyl_period_data` | 经期记录 |
| `zhyl_money_records` | 记账记录 |
| `zhyl_study_log` | 学习记录 |
| `zhyl_yoga_log` | 瑜伽记录 |
| `zhyl_health_log` | 养生记录 |
| `zhyl_daily_quote` | 每日一句 |

**清除所有数据**：在浏览器控制台执行 `localStorage.clear()` 后刷新。
